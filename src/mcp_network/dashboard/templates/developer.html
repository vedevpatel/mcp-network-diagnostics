Developer / API

Use the MCP server over HTTP with an API key. Your key's role determines which tools you can call.

Authentication

Send your API key with every request:

Authorization: Bearer mcp_<key_id>_<secret>

Or use the X-API-Key header with the full key string.

Create keys via the create_api_key tool (superuser) or from the dashboard Settings when using the API keys file.

HTTP endpoint

When the server is run with --transport streamable-http:

mcp-network --transport streamable-http --port 8000 --path /mcp
# Endpoint: http://localhost:8000/mcp

Use --require-auth to enforce API keys. Rate limits apply per key and globally (default 1000 req/min total).

Roles and tools

Keys are assigned a role. Each role can call its own tools plus all tools from lower roles.

  • consumer – Edge diagnostics only (no device access)
  • operator – + Device status, path, latency, read-only commands
  • admin – + Agent, intents, incidents, list/revoke keys
  • superuser – + Create API keys, full command access

Example

# List tools (MCP protocol)
curl -X POST http://localhost:8000/mcp \
  -H "Authorization: Bearer mcp_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

Clients that support MCP over HTTP (e.g. Claude Desktop with streamable-http URL) can connect to http://your-host:8000/mcp and pass the API key in the client config.
